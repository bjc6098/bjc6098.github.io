# 제라온 게임스튜디오 홈페이지

백호 로고를 활용한 PC·모바일 홈페이지와 네 게임 탭입니다. 리아의 모험에는 소개, 줄거리, 특징 4개, 실제 게임 화면 4장, 전용 FAQ 6개와 스토리·조작 문의 항목을 추가했습니다. 던전을 지켜라에는 소개, 특징, 화면 미리보기 4장, FAQ 6개와 티켓·배속 구매 문의 항목을 추가했습니다.

## GitHub 업로드

1. ZIP의 압축을 풉니다.
2. [bjc6098.github.io 저장소](https://github.com/bjc6098/bjc6098.github.io)를 열고 기존 `index.html`이 있는 루트에 이 파일들을 업로드합니다.
3. `index.html`, `app-ads.txt`, `assets/` 폴더 전체를 함께 올립니다. `site`라는 상위 폴더를 새로 만들 필요는 없습니다.
4. 변경사항을 커밋하면 기존 GitHub Pages 설정으로 [홈페이지](https://bjc6098.github.io/)에 반영됩니다.

`assets/`의 하위 폴더와 파일명은 그대로 유지하세요. 저장소의 다른 파일을 지울 필요는 없습니다. 별도 npm 설치나 웹 빌드 과정이 없는 정적 홈페이지입니다.

리아 탭의 직접 주소는 `https://bjc6098.github.io/#ria`이며, 화면 미리보기는 `#ria-screens`, 고객지원은 `#ria-support`로 바로 열 수 있습니다.

던전 탭의 직접 주소는 `https://bjc6098.github.io/#dungeon`입니다.

## 편집할 파일

- `index.html`: 화면 구성, 게임 소개, `game-catalog`의 게임별 문의 항목과 FAQ
- `assets/studio.css`: 색상, 레이아웃, PC·모바일 디자인
- `assets/app.js`: 게임 탭, 문의 양식, 화면 확대
- `assets/brand/`: 백호와 ZERAON 워드마크
- `assets/ria/`: 리아 앱 아이콘과 실제 게임 캡처 4장 (1600×900 가로 화면)
- `assets/dungeon/`: 던전 배너, 앱 아이콘, 화면 미리보기 4장
- `assets/original/`: 기존 슬라임 이미지와 픽셀 폰트, 폰트 라이선스

기존 문의 이메일 `bjc6098@gmail.com`, 슬라임 내용, `app-ads.txt`, 폰트 라이선스는 공개 홈페이지 원본에서 유지했습니다. 던전 화면은 실제 게임 자산과 UI로 구성한 미리보기입니다.

## 리아의 모험 콘텐츠

소개와 FAQ는 현재 게임의 대사·조작·저장 동작을 확인해 작성했습니다. 챕터 종료 때 저장되는 진행 상황을 설명하며, 매 이동이나 대화마다 자동 저장된다고 안내하지 않습니다. 이미지는 Windows 게임 렌더러로 촬영한 실제 플레이 화면이며 iOS 기기 촬영 화면으로 표시하지 않습니다. 가로 화면의 원본 구도를 유지하고, 모바일에서는 가로 스크롤과 화면 확대를 지원합니다.

GitHub Pages에 업로드할 ZIP에는 홈페이지에 필요한 정적 파일만 포함됩니다. QA 결과와 미리보기 이미지는 ZIP 바깥에 별도로 저장됩니다.

리아 추가 검증: PC·모바일 320/390/768/1440px에서 가로 화면 비율과 페이지 넘침 여부를 확인했습니다. 리아 탭·갤러리 직접 주소와 새로고침·FAQ·문의 메일 내용·게임별 초안 보존·키보드 탭 전환·이미지 확대 및 Escape 닫기를 확인했고, JavaScript 오류와 누락 파일은 없었습니다.
